# flutter_liquid_glass_tab_bar example

Four tabs of scrolling cards, a toggleable mini-player card in the bar's slot,
and a settings tab with dark mode, RTL, text scale, reduce motion and a
2–6 tab-count picker.

```sh
fvm flutter run
```

Run on a real device with Impeller enabled (the template already sets the
iOS plist key and the Android manifest meta-data) to see the refractive
material; simulators and `flutter test` show the blur fallback.
